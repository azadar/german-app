# Deutsch 80/20 (PWA)
Run locally: VS Code + "Live Server" extension -> right-click index.html -> Open with Live Server.
Deploy: push to GitHub -> Settings -> Pages -> Deploy from branch `main`, folder `/ (root)`.
Install on Windows: open the Pages link in Edge -> ... -> Apps -> Install this site as an app.
Add words: append objects {"de","p","en","ur"} to words.json (order = priority). Bump CACHE name in sw.js (deutsch-v2) after changes.
